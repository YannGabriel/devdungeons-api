1. Visão Geral

Base URL: http://localhost:3000/api
Swagger interativo: http://localhost:3000/api/docs
Formato: JSON em todas as requisições e respostas.
Header obrigatório nas rotas protegidas: Authorization: Bearer <token>
Rotas públicas (não precisam de token): GET em linguagens, GET em níveis, GET em questões, POST /auth/register, POST /auth/login, POST /auth/refresh.
Todas as demais exigem o JWT no header Authorization.

2. Como Autenticar

O fluxo completo em 3 passos:

PASSO 1
Cadastre-se ou faça login

Request

POST http://localhost:3000/api/auth/login
Content-Type: application/json

{
  "email": "joao@email.com",
  "password": "123456"
}

Response

{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 86400,
  "user": { "id": "uuid", "username": "João", ... }
}
PASSO 2
Use o accessToken em todas as requisições protegidas 
GET http://localhost:3000/api/auth/me
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
PASSO 3
Renove o token quando expirar 
POST http://localhost:3000/api/auth/refresh
Content-Type: application/json

{ "refreshToken": "eyJhbGci..." }

3. Módulo Auth

POST /api/auth/register Público

Cadastra um novo usuário. Opcionalmente associa linguagens de interesse com um nível inicial. Retorna tokens prontos para uso — não precisa fazer login separado.

Body

CampoTipoObrigatórioDescrição
usernamestringSimNome de exibição
emailstring (email)SimE-mail único
passwordstring (min 6)SimSenha (armazenada com bcrypt)
languageIdsstring[]NãoArray de UUIDs de linguagens de interesse
levelIdstring (uuid)NãoNível inicial para todas as linguagens selecionadas

Exemplo de Request

{
  "username": "João Silva",
  "email": "joao@email.com",
  "password": "minhasenha",
  "languageIds": ["uuid-javascript", "uuid-python"],
  "levelId": "uuid-basico"
}

Resposta 201

{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 86400,
  "user": {
    "id": "uuid",
    "username": "João Silva",
    "email": "joao@email.com",
    "role": "USER",
    "user_level": 0,
    "user_experience": 0,
    "languages": [
      {
        "id": "uuid",
        "language": { "id": "uuid", "name": "JavaScript" },
        "level": { "id": "uuid", "name": "Básico", "xp": 50 }
      }
    ]
  }
}

Respostas de Erro

StatusMotivo
400Dados inválidos (email mal formatado, senha curta, campo obrigatório ausente)
409E-mail já cadastrado
POST /api/auth/login Público

Autentica com e-mail e senha. Retorna accessToken (padrão: 24h) e refreshToken (padrão: 7 dias).

Body

{
  "email": "joao@email.com",
  "password": "minhasenha"
}

Resposta 200

{
  "accessToken": "eyJhbGci...",
  "refreshToken": "eyJhbGci...",
  "expiresIn": 86400,
  "user": { "id": "uuid", "username": "João Silva", "email": "joao@email.com",
             "role": "USER", "user_level": 2, "user_experience": 350, "languages": [...] }
}

Respostas de Erro

StatusMotivo
401E-mail não encontrado ou senha incorreta
GET /api/auth/me Protegido

Retorna o perfil completo do usuário autenticado: dados pessoais, nível global, XP e todas as linguagens associadas com seus respectivos níveis.

Request

GET /api/auth/me
Authorization: Bearer <accessToken>

Resposta 200

{
  "id": "uuid",
  "username": "João Silva",
  "email": "joao@email.com",
  "role": "USER",
  "user_level": 2,
  "user_experience": 350,
  "languages": [
    {
      "id": "uuid-assoc",
      "language": { "id": "uuid", "name": "JavaScript" },
      "level": { "id": "uuid", "name": "Básico", "xp": 50 }
    }
  ]
}
POST /api/auth/refresh Público

Gera um novo par de tokens sem exigir login novamente. Use quando o accessToken expirar.

Body

{ "refreshToken": "eyJhbGci..." }

Resposta 200

{ "accessToken": "...", "refreshToken": "...", "expiresIn": 86400 }

Respostas de Erro

StatusMotivo
401Refresh token inválido ou expirado

4. Módulo Usuários

Todos os endpoints de usuário (exceto POST /api/user) requerem autenticação via JWT.
POST /api/user Público

Cria um usuário diretamente (sem retornar token). Para o fluxo completo de cadastro com token, prefira POST /api/auth/register.

Body

{ "username": "Ana", "email": "ana@email.com", "password": "123456" }

Resposta 201

{ "id": "uuid", "username": "Ana", "email": "ana@email.com",
  "role": "USER", "user_level": 0, "user_experience": 0 }
GET /api/user/:id Protegido

Busca um usuário pelo UUID. Senha nunca é retornada.

Parâmetros de rota

ParâmetroTipoDescrição
iduuidID do usuário

Resposta 200

{ "id": "uuid", "username": "Ana", "email": "ana@email.com",
  "role": "USER", "user_level": 1, "user_experience": 200 }
PATCH /api/user/:id Protegido

Atualiza username, email ou senha. Todos os campos são opcionais. A senha nova é automaticamente hasheada com bcrypt.

Body (todos opcionais)

{ "username": "Novo Nome", "email": "novo@email.com", "password": "novasenha" }

Respostas de Erro

StatusMotivo
404Usuário não encontrado
409Novo e-mail já pertence a outro usuário
PATCH /api/user/update-experience Protegido

Adiciona XP a um usuário manualmente. Se o total atingir 1000 XP, o nível global sobe automaticamente e o excedente é carregado para o próximo nível.

Body

{ "id": "uuid-do-usuario", "user_experience": 50 }

Resposta 200

{ "message": "XP atualizado para 400" }
// ou, ao subir de nível:
{ "message": "Parabéns! Você subiu para o nível 3" }
O quiz credita XP automaticamente. Este endpoint é para casos manuais ou administrativos.

5. Módulo Linguagens

GET sem token. POST, PATCH e DELETE exigem JWT.
GET /api/programming-languages Público

Lista todas as linguagens em ordem alfabética. Seeded automaticamente: HTML, CSS, Python, JavaScript.

Resposta 200

[
  { "id": "uuid", "name": "CSS", "created_at": "2024-01-01T...", "updated_at": "..." },
  { "id": "uuid", "name": "HTML", ... },
  { "id": "uuid", "name": "JavaScript", ... },
  { "id": "uuid", "name": "Python", ... }
]
GET /api/programming-languages/:id Público

Busca uma linguagem pelo UUID.

POST /api/programming-languages Protegido

Cria uma linguagem de programação. O nome deve ser único (máx. 100 chars).

Body

{ "name": "TypeScript" }
PATCH /api/programming-languages/:id Protegido

Body

{ "name": "TypeScript 5" }
DELETE /api/programming-languages/:id Protegido

Remove a linguagem. Cascade: todas as questões associadas são removidas junto.

Resposta 200

{ "message": "Linguagem uuid removida com sucesso" }

6. Módulo Níveis de Conhecimento

Os níveis Básico (50 XP), Intermediário (75 XP) e Avançado (100 XP) são criados automaticamente na inicialização. O campo xp define quantos pontos o usuário ganha ao acertar uma questão daquele nível.
GET /api/knowledge-levels Público

Resposta 200

[
  { "id": "uuid", "name": "Avançado",      "xp": 100, ... },
  { "id": "uuid", "name": "Básico",        "xp": 50,  ... },
  { "id": "uuid", "name": "Intermediário", "xp": 75,  ... }
]
POST /api/knowledge-levels Protegido

Body

{ "name": "Expert", "xp": 150 }  // xp é opcional, default 0
PATCH /api/knowledge-levels/:id Protegido

Body (ambos opcionais)

{ "name": "Iniciante", "xp": 30 }
DELETE /api/knowledge-levels/:id Protegido

Remove o nível. Questões associadas ficam com level_id = null. Associações usuário-linguagem-nível são removidas em cascade.

7. Módulo Questões

Leitura (GET) é pública. Criação, edição, remoção e resposta avulsa exigem JWT.
GET /api/questions Público

Lista todas as questões com linguagem, nível e alternativas incluídos. Ordenado por created_at DESC.

Resposta 200 (estrutura de uma questão)

{
  "id": "uuid",
  "enunciado": "Qual método exibe mensagem no console?",
  "language": { "id": "uuid", "name": "JavaScript" },
  "level": { "id": "uuid", "name": "Básico", "xp": 50 },
  "alternatives": [
    { "id": "uuid", "descricao": "console.log()", "correta": true  },
    { "id": "uuid", "descricao": "print()",        "correta": false },
    ...
  ]
}
GET /api/questions/by-language/:languageId Público

Filtra questões por linguagem. Retorna array com a mesma estrutura do GET geral.

GET /api/questions/by-level/:levelId Público

Filtra questões por nível de conhecimento.

POST /api/questions Protegido

Cria uma questão com exatamente 5 alternativas, sendo obrigatoriamente 1 correta. Linguagem é obrigatória; nível é opcional.

Body

{
  "enunciado": "Qual tag cria um link em HTML?",
  "language_id": "uuid-html",
  "level_id": "uuid-basico",
  "alternatives": [
    { "descricao": "<a>",         "correta": true  },
    { "descricao": "<link>",      "correta": false },
    { "descricao": "<href>",      "correta": false },
    { "descricao": "<url>",       "correta": false },
    { "descricao": "<hyperlink>", "correta": false }
  ]
}

Respostas de Erro

StatusMotivo
400Número de alternativas diferente de 5 ou número de corretas diferente de 1
404language_id ou level_id não encontrado
PATCH /api/questions/:id Protegido

Atualiza enunciado, linguagem ou nível. Para editar alternativas use os endpoints de alternativas.

Body (todos opcionais)

{ "enunciado": "Novo enunciado", "language_id": "uuid", "level_id": "uuid" }
DELETE /api/questions/:id Protegido

Remove a questão e todas as suas alternativas em cascade.

POST /api/questions/:id/answer Protegido

Resposta avulsa — fora de uma sessão de quiz. Verifica se a alternativa está correta e credita XP ao usuário autenticado. Não guarda histórico de respostas.

Body

{ "alternative_id": "uuid-da-alternativa-escolhida" }

Resposta 200

{
  "question_id": "uuid",
  "chosen_alternative_id": "uuid",
  "correct": true,
  "correct_alternative_id": "uuid",
  "question_xp": 50,
  "xp_earned": 50,
  "user_update": { "message": "XP atualizado para 400" }
}
Para um fluxo completo com histórico, fila de 10 questões e XP ao final, use o módulo Quiz.
GET /api/questions/:id/alternatives Público

Lista as alternativas de uma questão em ordem de criação (ASC).

POST /api/questions/:id/alternatives Protegido

Adiciona alternativa a uma questão que ainda não atingiu 5 alternativas.

Body

{ "descricao": "Nova alternativa", "correta": false }
StatusMotivo de erro
400Questão já tem 5 alternativas ou já possui 1 correta e correta: true foi enviado
PATCH /api/questions/alternatives/:alternativeId Protegido

Atualiza texto ou status de correta. Ao enviar correta: true, as demais alternativas da mesma questão são automaticamente desmarcadas.

Body (ambos opcionais)

{ "descricao": "Texto corrigido", "correta": true }
DELETE /api/questions/alternatives/:alternativeId Protegido

Remove uma alternativa. Só é permitido se a questão tiver mais de 5 alternativas (adicione a substituta antes de remover).

8. Módulo Quiz — Fila de 10 Questões

Todos os endpoints do Quiz exigem autenticação JWT.
O quiz seleciona aleatoriamente até 10 questões para a linguagem/nível escolhido, rastreia cada resposta e credita o XP total ao usuário ao finalizar. As respostas corretas não são reveladas antes de cada questão ser respondida.
POST /api/quiz/start Protegido

Inicia uma nova sessão de quiz. Se já existir uma sessão IN_PROGRESS para a mesma linguagem/nível, ela é retomada automaticamente — não cria duplicatas.

Body

{
  "language_id": "uuid-javascript",
  "level_id":    "uuid-basico"   // opcional
}

Resposta 201 (sessão iniciada)

{
  "session_id": "uuid-sessao",
  "status": "IN_PROGRESS",
  "language": { "id": "uuid", "name": "JavaScript" },
  "level": { "id": "uuid", "name": "Básico", "xp": 50 },
  "progress": {
    "questions_answered": 0,
    "questions_total": 10,
    "current_score": 0,
    "total_xp_earned": 0,
    "accuracy_percentage": 0,
    "current_question_order": 1,
    "is_complete": false,
    "completed_at": null
  },
  "questions": [
    {
      "order": 1,
      "question_id": "uuid",
      "enunciado": "Qual palavra-chave declara variável com escopo de bloco?",
      "alternatives": [
        { "id": "uuid", "descricao": "var"     },
        { "id": "uuid", "descricao": "let"     },
        { "id": "uuid", "descricao": "const"   },
        { "id": "uuid", "descricao": "def"     },
        { "id": "uuid", "descricao": "declare" }
      ],
      "answered": false, "your_answer": null, "correct": null,
      "correct_alternative_id": null, "xp_earned": 0
    },
    // ... questões 2 a 10 (sem correta revelada)
  ]
}

Respostas de Erro

StatusMotivo
400Questões insuficientes (mínimo 3 disponíveis para a linguagem/nível)
404Linguagem ou nível não encontrado
POST /api/quiz/:sessionId/answer Protegido

Registra a resposta para uma questão da sessão. Ao responder a última questão, a sessão é finalizada e o XP total é creditado ao usuário automaticamente.

Body

{
  "question_id":    "uuid-da-questao",
  "alternative_id": "uuid-da-alternativa-escolhida"
}

Resposta 200 — questão intermediária

{
  "question_order": 3,
  "correct": true,
  "correct_alternative_id": "uuid-correta",
  "xp_earned": 50,
  "session": {
    "id": "uuid-sessao",
    "questions_answered": 3,
    "questions_total": 10,
    "current_score": 2,
    "total_xp_earned": 100,
    "is_complete": false,
    "next_question_order": 4,
    "completed_at": null
  },
  "final_results": null
}

Resposta 200 — última questão (sessão completa)

{
  "question_order": 10,
  "correct": false,
  "correct_alternative_id": "uuid-correta",
  "xp_earned": 0,
  "session": {
    "questions_answered": 10, "questions_total": 10,
    "current_score": 7, "total_xp_earned": 350,
    "is_complete": true, "next_question_order": null,
    "completed_at": "2024-01-15T14:32:00.000Z"
  },
  "final_results": {
    "correct_answers": 7,
    "wrong_answers": 3,
    "accuracy_percentage": 70,
    "total_xp_earned": 350,
    "questions_summary": [
      { "order": 1, "enunciado": "...", "your_answer_id": "uuid",
        "correct_answer_id": "uuid", "correct": true, "xp_earned": 50 },
      // ... questões 2 a 10
    ]
  }
}

Respostas de Erro

StatusMotivo
400Questão já respondida / alternativa inválida / sessão já finalizada
403A sessão pertence a outro usuário
404Sessão não encontrada
GET /api/quiz/history Protegido

Histórico de todas as sessões do usuário autenticado, da mais recente para a mais antiga.

Resposta 200

[
  {
    "id": "uuid", "status": "COMPLETED",
    "language": { "name": "JavaScript" },
    "level": { "name": "Básico", "xp": 50 },
    "score": 7, "total_questions": 10,
    "accuracy_percentage": 70, "total_xp_earned": 350,
    "started_at": "2024-01-15T14:20:00.000Z",
    "completed_at": "2024-01-15T14:32:00.000Z"
  }
]
GET /api/quiz/:sessionId Protegido

Estado completo de uma sessão. Questões já respondidas mostram correta nas alternativas; questões não respondidas ocultam esse campo.

9. Módulo Nível do Usuário por Linguagem

Registra em qual nível um usuário está para cada linguagem que estuda. Um usuário só pode ter um nível por linguagem. Todos os endpoints exigem JWT.
GET /api/user-language-levels/by-user/:userId Protegido

Retorna todas as linguagens e níveis de um usuário. Ideal para renderizar o dashboard de progresso.

Resposta 200

[
  {
    "id": "uuid-assoc",
    "user_id": "uuid-user",
    "language": { "id": "uuid", "name": "JavaScript" },
    "level": { "id": "uuid", "name": "Básico", "xp": 50 },
    "created_at": "...", "updated_at": "..."
  }
]
POST /api/user-language-levels Protegido

Associa um usuário a uma linguagem com nível inicial. Também feito automaticamente pelo POST /auth/register se languageIds e levelId forem enviados.

Body

{ "user_id": "uuid", "language_id": "uuid", "level_id": "uuid" }

Respostas de Erro

StatusMotivo
409Usuário já possui nível cadastrado para esta linguagem
404user_id, language_id ou level_id não encontrado
PATCH /api/user-language-levels/:id Protegido

Avança o nível do usuário em uma linguagem (ex: Básico → Intermediário).

Body

{ "level_id": "uuid-intermediario" }
DELETE /api/user-language-levels/:id Protegido

Remove a associação. O usuário deixa de ter aquela linguagem em seu perfil.

10. Códigos de Erro

StatusSignificadoCausas comuns
400 Bad Request Dados inválidos Campo obrigatório ausente, tipo errado, número de alternativas ≠ 5, questão já respondida
401 Unauthorized Não autenticado Token ausente, expirado ou mal formado. Fazer login novamente
403 Forbidden Acesso negado Sessão de quiz pertence a outro usuário
404 Not Found Recurso não encontrado ID inválido ou registro deletado
409 Conflict Conflito de dados únicos E-mail duplicado, nome de linguagem/nível duplicado, usuário já tem nível para a linguagem

Todos os erros seguem o formato padrão do NestJS:

{
  "statusCode": 400,
  "message": "Cada questão deve possuir exatamente 5 alternativas",
  "error": "Bad Request"
}
